# My Homelab

## Overview  
This repository documents my personal homelab setup; hardware, software, network services, and media management tools. It helps me keep track of configurations, automation, and deployment.

## Hardware  
- **Laptop** (Host)  
  - **CPU:** `AMD Ryzen 5 5600H`  
  - **GPU:** `NVIDIA GTX 1650`  
  - **RAM:** `16 GB`  
  - **OS:** `AlmaLinux`

- **Personal Desktop** (AI Backend / LM Studio Host)  
  - **CPU:** `AMD Ryzen 7 7800X3D`  
  - **GPU:** `AMD Radeon RX 9070 XT`  
  - **RAM:** `32 GB`
  - **OS:** `Windows 10 IoT Enterprise LTSC`

- **Storage**
  - **NVMe:** `2 x 500 GB` (System/Cache)
  - **NVMe:** `1 x 2 TB` (High-speed Storage)
